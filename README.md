# Sales Performance Analysis & Excel Dashboard

Project analisis data penjualan menggunakan Microsoft Excel untuk mengevaluasi performa penjualan berdasarkan produk, platform, kota, periode waktu, dan karakteristik pelanggan. Hasil analisis kemudian disajikan dalam bentuk dashboard interaktif untuk mempermudah eksplorasi data dan menghasilkan insight bisnis.

## Gambaran Umum

Project ini menggunakan data transaksi penjualan yang diolah dan dianalisis menggunakan Microsoft Excel. Proses analisis mencakup penggunaan formula, filtering, Pivot Table, Pivot Chart, dan Slicer. Hasil analisis kemudian divisualisasikan melalui dashboard interaktif yang menyajikan berbagai indikator dan visualisasi terkait performa penjualan. 

## Business Questions

Analisis dilakukan untuk menjawab beberapa pertanyaan bisnis utama:

1. Produk apa yang menghasilkan total penjualan tertinggi?
2. Platform mana yang menghasilkan total pendapatan terbesar?
3. Bagaimana distribusi total penjualan dan jumlah barang di setiap kota?

## Analisis Data

Analisis dilakukan untuk mengevaluasi performa penjualan berdasarkan beberapa dimensi, meliputi produk, platform, kota, periode waktu, dan karakteristik pelanggan. Data diringkas menggunakan Pivot Table dan kemudian divisualisasikan melalui Pivot Chart untuk mengidentifikasi pola penjualan, perbedaan performa antar kategori, serta distribusi transaksi berdasarkan berbagai karakteristik. 

## Excel Dashboard

Hasil analisis disajikan dalam bentuk dashboard interaktif menggunakan Microsoft Excel. Dashboard mencakup visualisasi:

- Monthly Sales Trend
- Revenue by Platform
- Total Sales by Product
- Sales & Quantity by City
- Gender Distribution

Dashboard dilengkapi dengan filter interaktif berdasarkan Order Date, Platform, City, dan Gender untuk memudahkan eksplorasi data pada berbagai segmen.
